# patient-Doctor-analysis-project-
This repository contains SQL scripts for analyzing hospital patient and doctor data.
The project covers:

 Table creation
 Inserting sample data
 Basic SQL queries
 WHERE + ORDER BY + LIMIT
 GROUP BY + HAVING
 Joins (INNER, LEFT, RIGHT, FULL OUTER)
 Subqueries (single-row, multi-row, multi-column)
 Window Functions (RANK, ROW_NUMBER, LAG, AVG OVER, etc.)
 Data cleaning (delete duplicates using window functions)
